# AI Journal Enrichment

AI journal enrichment is deferred and is not part of the v1 product surface.

The v1 branch should not expose commands, repositories, settings, provider keys, UI widgets, generated SDK hooks, or API paths for entry insights, suggestions, relation suggestions, accepted AI tags, or weekly summaries.

Existing migrations are preserved for compatibility, but migration presence is not shipped behavior.

Future work can revisit enrichment after v1 with a fresh product plan, including review/edit/dismiss flows, privacy copy, sync behavior, provider policy, tests, and docs.
